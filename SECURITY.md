# Security policy

ToneDex is a solo, unpaid fan project. Reports are welcome and taken seriously, but responses are best effort.

## Scope

- The live site at https://tonedex.app
- The API at https://api.tonedex.app
- The code in this repository

Report issues in PokeAPI, Render or Google sign-in to those projects.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: [open a report](https://github.com/atcarter/tonedex/security/advisories/new). Don't open a public issue for a security problem.

## Supported versions

Only what's deployed from `main` is supported. There are no releases.

## What to expect

There's no fixed response timeline and no bug bounty. Reports are read and fixed as time allows.
